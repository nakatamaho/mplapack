## Where it is used

They provide the fixed-precision real `cu_freal<PB>` (bit-exact with MPFR
round-to-nearest), its correctly rounded division and square root, and the
complex `cu_fcomplex<PB>` (bit-exact with MPC for +, -, *) of the CPU MPFR
BLAS kernels: `../openmp/Rgemm_freal_{x86,generic}.cpp` (Rgemm) and
`../openmp/Rfreal_blas_<PB>.cpp` (the other routines, see
`../openmp/Rfreal_blas.h`). The code of those files and of the headers they
include from `../openmp` (`Rgemm_freal*.h`, `Rfreal_*.h`, `Rfreal_blas.cpp`)
is BSD. Since the LGPL files are headers of templates, their code is
compiled into

- `libmplapack_mpfr_opt` (`mpblas/optimized/mpfr`),
- `libmplapack_mpfr_opt_cuda` (`mpblas/optimized/mpfr/cuda`),

so these two libraries contain LGPL-3.0-or-later code, and distributing them
(or programs linked with them) carries the obligations of the LGPL for that
part. The other MPLAPACK libraries do not contain it.

`MPLAPACK_MPFR_CPU_FREAL=0` turns the kernels off at run time; it does not
remove the code from the libraries.
